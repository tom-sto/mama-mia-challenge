# mama-mia-challenge

Working git project for MAMA-MIA 2025 Challenge

This is the version of the code that I used to train the model for MICCAI in January 2026.

The file path for the data folder `my_preprocessed_data` will have to be changed in the code to point to the correct location in the OneDrive folder:

`MAMA-MIA Data/my_preprocessed_data`

Alternatively, the environment variable `MAMAMIA_DATA` can be set to the absolute path for `MAMA-MIA Data`

## To Run

`python trainMyUNet.py`
